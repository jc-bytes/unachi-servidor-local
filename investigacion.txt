FUENTES TÉCNICAS
Supabase · operación propia
La instalación propia asigna al operador la administración, las actualizaciones, los respaldos, la restauración, la disponibilidad y el monitoreo. No incluye los servicios administrados de respaldo y PITR de la plataforma.
https://supabase.com/docs/guides/self-hosting

Supabase · Docker y requisitos
Referencia oficial para la pila: mínimo 2 núcleos, 4 GB RAM y 40 GB SSD; recomendado 4+ núcleos, 8+ GB RAM y 80+ GB SSD. No es una garantía de capacidad para UNACHI. La guía distingue Linux servidor, Linux escritorio, Windows y macOS.
https://supabase.com/docs/guides/self-hosting/docker

Supabase · base de datos PostgreSQL
Base relacional PostgreSQL para registros relacionados, consultas y reglas de acceso. La aplicación, sus formularios, la calidad de datos y los informes institucionales deben diseñarse.
https://supabase.com/docs/guides/database/overview

Supabase · identidad y permisos
Auth gestiona usuarios y sesiones. Los permisos de cada unidad se implementan con políticas y roles. El modelo no incluye SAML SSO, SMS, identidad externa ni otros complementos.
https://supabase.com/docs/guides/auth

Supabase · archivos
Storage guarda documentos y otros archivos con controles de acceso. Enlazar un documento ya conservado en un repositorio puede evitar duplicarlo, si el acceso y las políticas institucionales lo permiten.
https://supabase.com/docs/guides/storage

Docker · licencia de Desktop
La documentación enumera educación entre usos gratuitos y entidades gubernamentales entre los de pago. Confirmar la clasificación aplicable a la universidad; no asumir una exención. Docker Engine en Linux es una alternativa distinta.
https://docs.docker.com/subscription-billing/desktop-license

Docker · Engine en Linux
Instalación de Engine en distribuciones Linux compatibles. La guía publica soporte por arquitectura; validar el hardware concreto antes de instalar.
https://docs.docker.com/engine/install/

PostgreSQL · licencia
PostgreSQL usa una licencia de código abierto sin tarifa de uso del software. Su operación, desarrollo y soporte siguen teniendo costo.
https://www.postgresql.org/about/licence/

Metabase · planes
Metabase Open Source permite consultas y tableros sin suscripción de software. Operación, recursos y condiciones de licencia se revisan aparte; funciones avanzadas pueden requerir planes de pago.
https://www.metabase.com/pricing

MODELO DE COSTO
Kit físico = equipo + UPS + dos discos + ajustes cotizados. Operación = electricidad + horas de soporte + otros gastos ingresados. No es una mensualidad de Supabase.
RAM y almacenamiento son referencias de planificación, pendientes de pruebas. Desarrollo, instalación, integración, migración, capacitación, impuestos, entrega, licencias, red, climatización y reemplazos requieren cotización.
